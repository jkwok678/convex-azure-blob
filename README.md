# Convex Azure Blob

[![npm version](https://badge.fury.io/js/convex-azure-blob.svg)](https://badge.fury.io/js/convex-azure-blob)

An [Azure Blob Storage](https://azure.microsoft.com/products/storage/blobs)
component for [Convex](https://convex.dev).

> This component is under development and not yet ready for use.

Found a bug? Feature request?
[File it here](https://github.com/jkwok678/convex-azure-blob/issues).

## Development

```sh
npm i
npm run dev
```

`npm run dev` starts a file watcher that rebuilds the component, along with the
example project backend, which installs and uses the component. Run
`npm run dev:frontend` to interact with it through a Vite app.

Run `npm test` to test the component, its client, and the example application.
